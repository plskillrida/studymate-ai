# StudyMate AI

An AI-powered study and revision assistant designed to help students understand, revise, and test themselves on their study material.

## Overview

StudyMate AI allows students to provide their study material and use AI-powered tools to make revision more effective.

The application will provide features such as:

- AI-generated summaries
- Question answering based on study material
- Automatically generated quizzes and MCQs
- Flashcard generation
- Revision and topic tracking

## Tech Stack

- **Frontend:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **AI:** OpenAI API
- **Backend:** Next.js Route Handlers
- **Database:** Supabase PostgreSQL
- **Authentication:** Supabase Auth
- **Validation:** Zod
- **Deployment:** Vercel



## Planned Features



### Study Material

Students can add or upload study material that can be used as the basis for AI-powered revision.

### AI Summaries

Generate concise summaries from longer study material.

### Ask Questions

Students can ask questions about their study material and receive AI-generated explanations.

### Quiz Generation

Generate MCQs and other quiz questions based on the provided material.

### Flashcards

Generate flashcards to help students revise important concepts.

### Progress Tracking

Track revision activity and identify topics that require additional practice.

## Getting Started



### Prerequisites

- Node.js (LTS)
- npm
- Git



### Installation

Clone the repository:

```bash
git clone <repository-url>
cd studymate-ai

```

Install dependencies:

```bash
npm install

```

Start the development server:

```bash
npm run dev

```

The application will be available at `http://localhost:3000`.
